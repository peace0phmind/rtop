# 三层等价证据的对抗性控制

状态：accepted。

## 已确认的挑战与默认决策

| 挑战 | 默认决策 |
| --- | --- |
| Ontop 测试并非完整规范 | 将 Ontop 的源码入口、启用测试、manifest、fixture 与明确 ignore 合并为分母；发现彼此矛盾时创建功能原子并差异裁决，不以单一测试结果覆盖。 |
| 差分执行器污染结果 | Ontop 与 rtop 必须由独立进程和独立结果采集路径执行；比较器不得调用被测解析器、serializer 或预期生成代码。 |
| 功能原子过粗 | 原子必须可独立裁决；一个测试类、一个 manifest 或一个 Rust 函数可以对应多个原子，但不能反过来掩盖未覆盖行为。 |
| 失败无法复现 | 每个失败保存失败指纹，并自动最小化到可提交的 fixture；未能重现的失败只能标为环境不确定性，不能视作通过。 |
| 覆盖率被辅助测试抬高 | 只统计带矩阵测试 ID 的执行覆盖；单元测试可补充诊断，但不可补足缺失的功能原子差分证据。 |
| 变异/生成式测试不稳定 | 它们仅用于发现新原子；一旦发现反例，须冻结为确定性 fixture 与差分用例，才进入关闭分母。 |
| 外部制品或许可漂移 | fixture 的来源、许可证、commit/blob hash、下载位置和再分发状态均为 provenance；不可复核或不可合法再分发的制品阻止该原子通过。 |
| CI 成功但供应链变化 | CI 固定工具链、容器 digest、Ontop 版本与规范化器 hash；缺失任一 artifact 使本次证据无效。 |
| 关闭后回归 | 矩阵、分母扫描、双边差分和层覆盖率为必跑保护分支 gate；任何变化重新打开受影响原子，而不是沿用历史通过。 |

## 强化关闭规则

除 ADR-0005 与 ADR-0006 的门槛外，关闭前还必须证明：

1. 每个功能原子可独立判定，且其差分 harness 与被测实现独立；
2. 每个失败、ignore、范围外或环境不确定性都有失败指纹和裁决；
3. CI artifact 可重放并包含所有外部制品与许可证 provenance；
4. 变异/生成式测试发现的反例已经冻结，或明确记录为何不进入固定分母；
5. 关闭后的保护分支仍持续执行全部证据保鲜 gate。
